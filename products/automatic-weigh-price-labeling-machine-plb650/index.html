PLB650

Why Use a Weigh Price Labeling Machine?

Two trays of seafood or meat may look the same but weigh differently. When pricing is by weight, manual work means weighing, calculating, entering data, printing and applying labels by hand. The PLB650 automates all of these steps, improving efficiency and reducing pricing and labeling errors.

01

Weigh the Package

Operators weigh each package on a scale by hand before pricing.

02

Calculate the Price

The selling price must be worked out by hand for every weight.

03

Enter Data into a Printer

Weight and price data are typed into the printer one by one.

04

Print the Label

Each label is printed separately after the data is entered by hand.

05

Apply the Label Manually

Labels are stuck on by hand, package after package.

PLB650

Key Features

01

Dynamic Weighing

Weighing happens while products move continuously through the machine. There is no need to stop each product for separate weighing. Standard range 1–5 kg.

02

Real-Time Price Calculation

The control system calculates product pricing automatically from the actual weight, preset unit price and stored product information. It measures the weight, retrieves the stored unit price, calculates the selling price, transfers the data to the printer and prints the final price on the label.

03

Automatic Label Printing

The integrated printing unit prints variable information on every label: price, net weight, barcode, QR code, logo, product name, text and graphics.

04

Automatic Print-and-Apply Labeling

After printing, the labeling mechanism transfers and applies the label automatically. It handles packages with slightly uneven surfaces, and the working height is adjustable.

05

Up to 50 Packages per Minute

Continuous conveyor operation processes up to approximately 50 packages per minute, depending on product size, spacing, label size and printing content.

06

±5 g Weighing Accuracy

Standard dynamic weighing accuracy is approximately ±5 g, depending on product stability, conveyor speed and operating conditions.

07

Data Storage Function

Product information and operating data are stored in the system to simplify repeated production with multiple products, prices or label formats.

08

Customizable Control Panel Language

The operating interface language can be customized for different export markets.

09

Adjustable Conveyor Speed

Conveyor speed adjusts from approximately 0–50 m/min to match different production capacities and upstream equipment.

10

Adjustable Labeling Height

The labeling unit adjusts vertically to the height and shape of each package, so different packs run on the same machine.

About us

Printing System & Label Size

The integrated printer generates labels containing both fixed and variable information. The label winding path feeds labels through the print head, where price, weight and barcode are printed before the label is transferred to the applicator.

The standard supported label size is 30 × 30 mm minimum to 100 × 100 mm maximum. Both thermal and thermal-transfer label materials can be used. The final label specification should be confirmed according to the required printing content.
